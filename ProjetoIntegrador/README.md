# Wd decorações — Landing Page

Landing page de uma empresa de drywall de Foz do Iguaçu, desenvolvida como trabalho acadêmico de Engenharia de Software.

Feita apenas com **HTML, CSS e JavaScript puros** (sem frameworks ou bibliotecas). Usa Google Fonts (Montserrat e Open Sans).

## Funcionalidades

- Header fixo com menu hambúrguer no celular
- Scroll suave nos links do menu
- Seções: serviços, diferenciais, como funciona, depoimentos, FAQ e formulário de orçamento
- FAQ em accordion
- Formulário com validação, máscara de telefone e envio pelo WhatsApp (abre a conversa com os dados já preenchidos, sem backend)
- Botão flutuante de WhatsApp
- Layout responsivo (mobile-first), testado em 375px, 768px e 1280px

## Estrutura

```
/index.html        -> estrutura da página
/css/style.css     -> estilos
/js/script.js      -> interações
/assets/img/       -> imagens
/README.md
```
